## D. 11/10 추가 조사 — 수상 모델 계열과 수상 피처 (리더보드 교훈 뒤)

배경: E11-10T1 제출 결과 내부 −3.83% 가 리더보드 +330만 원(내부 1% ≈ 86만 원)에 그침. 새 정보(GFS)는 리더보드로 그대로 옮겨졌지만 설정값 탐색·구조 개선은 덜 옮겨짐 → 다른 계열 모델·피처를 수상 해법 근거로 다시 고름.

### D1. 수상 모델 계열 (하루 전 NWP 태양광 중심)

| 대회 | 상위권 모델 | 우리에게 |

| POSTECH OIBC 2022·2023, 데이콘 2021 | WaveNet·LSTM+주의·Transformer·DNN·1D CNN | 데이터가 작고 OIBC 는 정확도 50%·창의성 30%·발표 20% 심사(2022 대상 WaveNet 은 정확도 3위) |
| 데이콘 2020 5위(우리 reference) | MLP·CNN·LSTM ≈ LightGBM(분위수 손실 2.05~2.22 vs 2.13~2.19), 54개 선형 스태킹 | 발전소 1곳, 작은 데이터 |
| TabReD 2024(시간순 분할, 피처 ~260) | 평균 순위: MLP-PLR 시드 앙상블 2.4, XGBoost 2.9, LGBM 3.1, 일반 MLP 5.0 | MLP 는 수치 임베딩 + 시드 평균일 때만 GBM 급 |

결론: 같은 NWP 표 데이터에서 신경망이 GBM 을 이긴 수치는 없음. 신경망을 섞은 일반적 이득 0~3%, 우리 추정 0 ~ −2%(가운데 −0.5~−1%). 넣는다면 작은 비중(1/6)의 보조 모델 — 레시피: 중요도 상위 100~150 피처, 학습 fold 로만 맞춘 분위수 변환, 발전소 임베딩, sigmoid×1.2 출력, L1 + 시간 가중, MLP 3×512 SiLU, AdamW, 배치 4096, 조기 종료는 학습 기간 마지막 1~2개월, 시드 3~5개.
투빅스 1D CNN 은 검증 누수(겹치는 창 무작위 fold)·평가 기간 정규화가 있어 참고 가치 낮음.
