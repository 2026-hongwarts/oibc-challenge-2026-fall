# 비슷한 대회 수상 해법 조사 — 가져올 것과 결과 (2026-11-09)

우리 문제: 하루 전(전날 17:00 KST) 기상예보로 태양광 발전소 253곳을 두 묶음으로 나눠 묶음별 시간 발전량을 예측, 벌금 = SMP × 시간 가중 절대오차.
판정 기준: 세 해(2024-25 / 2023-24 / 2022-23) 모두 벌금 감소 + 다른 시드 재현. 규정(`docs/대회_규정.md`)에 맞는지도 함께 적는다.

**상태**: ✅ 채택 · ❌ 시험 후 기각 · 🔄 진행 중 · ⬜ 후보(미시험) · 🚫 규정·조건상 불가

조사 결과 공통점: 상위권은 거의 모두 **그래디언트 부스팅 트리 + 여러 예보 출처 + 간단한 결합**. 우리 방향(LightGBM·XGBoost, GFS 추가, 같은 비중 앙상블)과 일치하고,
가장 큰 차이는 "예보 출처의 수"(우승팀 3개 → 우리는 지역 예보 A·B + GFS).
