# 피처 분석 (F9, 2026-11-09)

대상: 최종 후보(E9 계열)의 피처 54개. 모델: LightGBM(E9-00 설정, A 기압 포함, 시드 0).
방법: 학습 기간 세 fold(검증 연도 2024-25 / 2023-24 / 2022-23, 각각 직전 2년 학습)만 사용. 평가 기간으로는 아무것도 판단하지 않음(규정 §6).
코드: `analysis_lab/F9_피처분석.py`, 데이터 품질은 `analysis_lab/F6_데이터품질_점검.py`, 범주형 후보는 `analysis_lab/F8_범주형_후보.py`.

| 지표 | 뜻 |
|---|---|
| 벌금 기준 순열 중요도 | 검증 연도에서 그 피처(같은 변수의 10·17시 발행분, 앞뒤 시각 3개는 묶음)를 무작위로 섞었을 때 **대회 벌금**이 몇 % 늘어나는가. 클수록 점수에 기여 |
| SHAP | 예측 하나하나에서 그 피처가 발전율을 얼마나 올리고 내렸는가의 평균 크기(발전율 단위)와 방향 |
| gain | 나무가 분할에 그 피처를 쓴 정도. 많이 써도 점수 기여는 없을 수 있음 |
| 한낮 순위 상관 | 11 ~ 15시 실제 발전율과의 순위 상관을 학습 1년차·2년차·검증 연도 9개 기간에 따로 |

## 1. 점수에 기여하는 피처 (벌금 기준 순열 중요도, 세 fold 평균)

| 순위 | 피처(묶음) | 벌금 증가 | 해석 |
|:-:|---|---|---|
| 1 | 태양 고도 | +147% | 해가 얼마나 높은가 — 발전량의 뼈대 |
| 2 | **앞뒤 시각 A 습도** (1시간 전·후, 3시간 평균) | **+63%** | 날씨 피처 중 압도적 1위. 1시간 뒤 습도의 SHAP 이 태양 고도 다음 |
| 3 | 시각 | +16% | |
| 4 | cos 천정각 | +14% | 태양 고도와 순위가 완전히 같음(중복, 아래 5절) |
| 5 | B 자외선지수 | +7.7% | 일사의 직접 대용. 값이 클수록 발전율 ↑ (한낮 순위 상관 +0.51, 전 피처 중 최대) |
| 6 | 앞뒤 시각 A 운량 | +6.3% | |
| 7 | 태양 방위각 | +4.7% | |
| 8 | A 기온 | +2.3% | |
| 9 | B 습도 | +2.1% | |
| 10 | 설비용량 | +1.8% | |

- **날씨 정보의 중심은 A 습도와 운량, B 자외선지수**다. 앞뒤 시각 피처(X03)는 채택 실험(세 해 −0.7 / −1.5 / −2.3%)만이 아니라 중요도로도 핵심임이 확인됨.
- **자외선지수가 일사 대용으로 강하다**는 것은, 일사량 예보 자체(GFS DSWRF)를 넣으면 더 큰 정보가 될 수 있다는 근거다 → GFS 작업의 근거.

## 6. 결측·이상치·범주형 (F6, F8)

- 결측: 예보 학습 행 B사 0.077%, 평가 기간 0%. 파생 피처 최대 0.19%(전날 요약). 세 모델 모두 결측을 스스로 처리.
- 이상치: 물리 범위 밖 값 최대 0.006%(습도 102%, 하루 강수 212mm). 트리는 크기가 아닌 순서로 나눠 영향 없음. 타깃 발전율 최대 1.00, 정지 추정일 0.7% — 빼면 나빠짐(X13a·b).
- 범주형 후보의 고유값 비율: 시각 0.00002, 발전소 ID 0.0002, 예보 지점 0.00006 → 1 에 가까운 ID 성 컬럼 없음. 발전소 ID 는 가상 평가연도 예측 행의 16.9% 가 학습에 없던 발전소(실제 평가 창은 0%).
