# 피처 분석 (F9, 2026-11-09)

대상: 최종 후보(E9 계열)의 피처 54개. 모델: LightGBM(E9-00 설정, A 기압 포함, 시드 0).
방법: 학습 기간 세 fold(검증 연도 2024-25 / 2023-24 / 2022-23, 각각 직전 2년 학습)만 사용. 평가 기간으로는 아무것도 판단하지 않음(규정 §6).
코드: `analysis_lab/F9_피처분석.py`, 데이터 품질은 `analysis_lab/F6_데이터품질_점검.py`, 범주형 후보는 `analysis_lab/F8_범주형_후보.py`.

| 지표 | 뜻 |
|---|---|
| 벌금 기준 순열 중요도 | 검증 연도에서 그 피처(같은 변수의 10·17시 발행분, 앞뒤 시각 3개는 묶음)를 무작위로 섞었을 때 **대회 벌금**이 몇 % 늘어나는가. 클수록 점수에 기여 |
| SHAP | 예측 하나하나에서 그 피처가 발전율을 얼마나 올리고 내렸는가의 평균 크기(발전율 단위)와 방향 |
| gain | 나무가 분할에 그 피처를 쓴 정도. 많이 써도 점수 기여는 없을 수 있음 |
| 한낮 순위 상관 | 11 ~ 15시 실제 발전율과의 순위 상관을 학습 1년차·2년차·검증 연도 9개 기간에 따로 |

- **날씨 정보의 중심은 A 습도와 운량, B 자외선지수**다. 앞뒤 시각 피처(X03)는 채택 실험(세 해 −0.7 / −1.5 / −2.3%)만이 아니라 중요도로도 핵심임이 확인됨.

## 6-2. 값 분포에 따라 묶어서 범주화할 필요가 있는 피처 (검토만, 아직 시험 안 함)

트리 모델은 연속값을 내부에서 약 255개 구간으로 나눠 경계를 스스로 정하므로, 일반 연속 피처는 미리 묶어도 정보가 늘지 않는다.
다만 아래 유형은 묶음이 도움이 될 수 있다.

| 유형 | 컬럼 | 이유 |
|---|---|---|
| 원형 값 | 풍향 A·B | 359° 와 1° 가 붙어 있음을 트리가 모름 → 8방위 구간 또는 sin·cos |
| 0 이 대부분, 꼬리가 긴 값 | 강우·강설·결빙량, 총강수 | 큰 값은 표본이 적어 과적합 → 강도 등급 |
| 끝값이 드문 이산값 | 자외선지수(최고 등급 1행), 강수확률(90단계) | 드문 단계를 이웃과 합침 |
| 0·100 에 몰리는 값 | 운량 | 분포 모양에 맞춘 구간 |
| 표본이 적은 범주 | 발전소 ID(최소 48행) | 작은 범주끼리 합치기 |
| 전역 조절 | LightGBM `max_bin` | 구간 수 자체를 설정값 조정에 포함 |
