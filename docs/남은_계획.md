   - A2 여러 해 오차로 구성: 두 해를 이어 붙여 최적화 → 나머지 해로 평가, 해를 돌려 가며. 한 해판과 비교. (설명회 슬 26 "연도별 안정성") — 리더보드로 덜 옮겨진 원인 중 하나가 한 해 과적합일 수 있어 우선.

2. **출처별 전용 모델 확장** (11/10 에 통한 유일한 방향: S3)
   - GEFS 전용 XGBoost(S3 의 XGB 판, GPU 약 20분) → 다섯 모델에 더하기/바꾸기.
   - GFS 이전 실행(D-2 18시 UTC) 전용 모델: 받기 약 45분(공개 시각 기록) + 학습. HEFTCom 1위 세 번째 출처 +8%.

3. 통과한 것 시드 재현 → 앙상블 → 3% 넘으면 제출 파일.
