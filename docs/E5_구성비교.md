# E5 구성(G1/G2) 방법 비교

⑤ 묶음·구성·분석 · 2026-11-08 · 코드 `analysis_lab/E5_구성비교.py`

## 요약

- 발전소 253곳을 G1/G2 에 나누는 방법 다섯 가지를, **한 해를 빼고 정한 구성을 뺀 해에서 채점**하는 방식으로 비교했다.
- **B+c**(관측소별 반반 배정에서 출발해 세 해 오차로 다듬기, 신규 발전소·용량 여유 규칙 포함)가 평균 **−1.33%**(참조 구성 대비)로, 한 해 오차로 정하는 방식(평균 −0.79%)보다 세 해 모두 꾸준했다.
- 이 결과는 **`E4-08x2`(main 기준 모델: LightGBM, A 기압·계절 피처 제외)의 오차에 맞춘 것**이다.
- 추천 구성 파일: **`outputs/compositions/E5-Bpc_E4-08x2.csv`**
- 최종 모델 확정 후 추가 진행 여부를 결정한다.

## 기준

| 해 | 예측 | 참조 구성 벌금 (원) | 하한(한 묶음) 대비 참조 구성 |
|---|---|---:|---:|
| 2024-25 (가상 평가연도) | `E4-08x2` | 195,285,010 | +2.80% |
| 2023-24 | `E4-08x2_cut2023` | 103,122,231 | +4.28% |
| 2022-23 | `E4-08x2_cut2022` | 55,189,526 | +2.37% |

- 세 해 벌금은 기존 기록과 원 단위로 같다(재현 확인).
- 하한은 두 묶음을 하나로 합쳤을 때의 벌금으로, 어떤 구성도 이보다 낮을 수 없다. 참조 구성과 하한 사이 2~4% 가 구성으로 줄일 수 있는 최대 폭이다.

## 비교한 방법

| 이름 | 방법 | 쓰는 정보 |
|---|---|---|
| REF | `sites.csv` 참조 구성 (current_group A→G1) | — |
| CH | 한 해 오차로 `local_search` (참조 + 무작위 6개 시작점 중 최선). `chloe-solo` 의 `optimize_composition.py` 와 같은 방식 | 오차 1년 |
| A | CH 와 같은 탐색, 오차표를 여러 해 이어 붙여서 | 오차 2~3년 |
| B | 같은 B 관측소(`wb_station`) 발전소를 G1/G2 에 설비용량 반반으로 나눔. 오차는 보지 않음 | 관측소, 설비용량 |
| B+ | B 에서 출발한 `local_search` (A 와 같은 데이터) | B + 오차 2~3년 |
| B+c | B+ 와 같되 아래 두 규칙을 지키는 이동만 허용 | B + 오차 2~3년 |

B+c 규칙
1. 신규(2024-06 이후 편입) 발전소가 2곳 이상인 관측소는 두 묶음에 신규가 1곳 이상씩 남는다. 신규 발전소는 편입 전 오차가 0 으로 들어가 탐색이 배정을 판단하지 못하므로, 같은 관측소끼리 한쪽에 몰리지 않게 한다(역할 분담 문서의 ⑤ 주의 사항).
2. 묶음별 설비용량 ≥ 20,000kW + 100kW. 용량 미달 제출은 무효이고 횟수에 포함되므로 여유를 둔다.

## 평가 방법

한 해를 빼고 나머지 해의 오차로 구성을 정한 뒤, 뺀 해에서 참조 구성 대비 벌금 변화를 잰다. CH 는 남은 해 중 가장 최근 한 해, A·B+·B+c 는 남은 두 해를 쓴다. 각 해의 예측은 그해 이전 데이터로만 학습한 모델에서 나온 것이다.

| 채점한 해 | CH 가 쓴 해 | A·B+·B+c 가 쓴 해 |
|---|---|---|
| 2024-25 | 2023-24 | 2023-24 + 2022-23 |
| 2023-24 | 2024-25 | 2024-25 + 2022-23 |
| 2022-23 | 2024-25 | 2024-25 + 2023-24 |

## 결과

참조 구성 대비 벌금 변화, 낮을수록 좋음.

| 채점한 해 | CH | A | B | B+ | **B+c** |
|---|---:|---:|---:|---:|---:|
| 2024-25 | −0.35% | −0.23% | −1.31% | −1.35% | **−1.35%** |
| 2023-24 | −1.69% | −1.78% | −0.11% | −1.25% | **−1.04%** |
| 2022-23 | −0.34% | −1.14% | −0.67% | −1.64% | **−1.60%** |
| **평균** | −0.79% | −1.05% | −0.69% | −1.42% | **−1.33%** |

- CH 와 A 는 해에 따라 효과가 크게 달라진다. B 는 혼자서는 약하다.
- B 에서 출발해 오차로 다듬은 B+·B+c 가 세 해 모두 −1.0% 이상으로 가장 꾸준하다. B+c 는 규칙 때문에 B+ 보다 평균 0.09%p 낮으며, 시드 잡음(해마다 약 ±0.3%) 안이다.
- 같은 데이터로 정하고 채점한 값(낙관치)은 더 크게 나온다. 예: 2024-25 오차로 정한 CH 구성을 2024-25 로 채점하면 −2.11%, 다른 해에서는 −1.69%·−0.34%.
- 시험한 해가 셋뿐이고 2022-23 은 106곳만 실적이 있어, 순위는 확정이 아니라 경향으로 본다.

CH 재현: 2024-25 오차로 정한 CH 구성은 `chloe-solo` 의 `outputs/compositions/E4-08x2.csv` 와 253곳 모두 같다. 홀수 달로 정하고 짝수 달로 채점하면 −1.66%, 반대는 −1.73%.

## 최종 후보 점검 (세 해 오차로 정한 구성)

| 후보 | G1 / G2 (kW) | 신규가 한쪽에 몰린 관측소 (13곳 중) | 안정성 |
|---|---|---:|---|
| CH (2024-25) | 20,014.8 / 22,640.6 | 5 | — |
| A | 22,633.5 / 20,021.9 | 7 | 시작점 7개 결과가 모두 같은 발전소 8/253 |
| B | 21,245.6 / 21,409.8 | 0 | 항상 같음 |
| B+ | 22,644.3 / 20,011.1 | 3 | 데이터 4가지로 정한 결과가 모두 같은 발전소 147/253 |
| **B+c** | **22,531.0 / 20,124.3** | **0** | **같은 기준 152/253** |

- 안정성: A 는 시작점만 바꿔도 결과가 거의 매번 달라진다(평균 일치 56.8%). 벌금이 비슷한 구성이 많아 발전소 하나하나의 배정에는 근거가 약하다. B 를 뼈대로 쓰면 결과가 안정된다.
- 공식 채점기(`evaluate.py --composition`)로 2024-25 를 채점하면 참조 195,285,010원, CH 191,164,439원, B+c 191,877,613원이다. 둘 다 2024-25 오차로 정했거나 그해를 포함해 정한 구성이라 낙관치다.

## 규정 점검

- 구성은 학습 기간(2022-06 ~ 2025-05) 오차와 `sites.csv` 관측소 정보로만 정했다. 평가 기간 통계는 쓰지 않았다(규정 §6).
- 가중치는 학습 기간 SMP 를 썼다(규정 §8).
- 구성은 내부 검증으로만 정한다. 리더보드 점수를 보며 구성을 고치지 않는다(규정 §2).
