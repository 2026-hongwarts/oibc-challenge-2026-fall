## 0. 한눈에

**규모**
- 원천 입력 후보 69열(발전소 정보 9 + 예보 A 10변수 × 2발행분 + 예보 B 20변수 × 2발행분) 중 **그대로 쓰는 것은 18열**(발전소 3, A 8, B 7). 변수 단위로는 A 10개 중 5개, B 20개 중 5개.
- 가공 피처: 태양·시간 3개(+ GFS·GEFS 전용 모델은 cos 천정각 1개), 지역 예보 하루 요약 5개, 앞뒤 시각 6개, 외부 예보 GFS 215열 / GEFS 172열.
- 실측 기상·대상일 SMP·발전 실적은 규정상 입력이 될 수 없다.

**근거가 강한 결정** (다시 학습해 세 해 모두 개선 + 다른 시드 재현, 또는 리더보드 확인)
태양 고도 · GFS 1° 지역 일사량·운량(G2) · GFS 층별 운량(G5b) · GEFS 전용 모델(S3) · 앞뒤 시각(X03) · 하루 요약 중 '그날' 묶음 · 두 발행분을 한 모델에 · 발전소 맑은날 기준값 제외(E3, 리더보드).
규정·데이터 사실로 확정된 결정도 따로 근거가 필요 없다(기온 최고·최저 제외, 실측·SMP 제외, cos 천정각 중복).

**근거가 약하거나 없는 결정**
- **원 변수 목록의 출발점은 운영진 baseline.py 의 15개**다. 나중에 통계(F2)와 추가 실험(X01)으로 뒷받침했지만, 남은 변수 하나하나를 빼 보는 시험은 대부분 안 했다(B 운량·B 기온 등).
- **V07(피처 17개 빼기)은 시드 재현에 실패한다(새로 확인, §6.2).** 지금 모든 구성원의 바탕인데, "빼서 좋아졌다"가 아니라 "빼도 같다" 수준이다.
- 같은 변수에 대한 판단이 기준 모델에 따라 뒤집혔다(풍속·강수확률, 전날 요약) → 이 변수들은 효과가 0 근처라는 뜻(§6.4).
- GFS 일사량의 3시간 → 1시간 배분, 고정 상자 범위·1° 크기, GEFS 표준편차 배분은 따로 비교한 적이 없다(§6.5).

**새로 확인한 것 중 가장 중요한 것** (§6.3)
발전소 ID·예보 지점 ID 범주형(V02·V03)과 지점 거리·번호(X12)를 기각한 근거(2023-24 에서 +8 ~ +10%)는 **검증 연도에만 있는 '처음 보는 발전소'** 에서 나온 것이었다. 실제 평가 기간에는 처음 보는 발전소가 0% 다.
학습 때 본 발전소만 실험 예측으로 바꾸면 세 경우 모두 세 해 다 벌금이 줄었다(V02 −1.73 / −0.31 / −0.69%). 다만 같은 성격의 E3(발전소별 맑은날 기준값)도 이렇게 보면 좋아지는데 리더보드에서는 약 300만 원 손해였으므로, 이것만으로 채택할 근거는 못 된다.

**서로 바꿀 후보** (§7): 근거가 약한 결정은 대부분 효과가 0 근처라 바꿔도 잡음이다. 바꿀 여지가 있는 것은 ① GEFS 표준편차 시각 배분(설계와 구현이 다름 → 원값으로) ② GFS 일사량 표현(배분 방식 미검증 → 블록 값 또는 청천 지수) ③ B 자외선 앞뒤 시각(미시험) ④ 발전소 ID(기각 근거가 평가 조건에 해당 없음) 네 개다.

**기압 같은 체계적 원인** (§8): **L1 손실이 묶음 합을 맑을 때 2 ~ 3% 과대, 흐릴 때 과소로 미는 치우침**을 찾았다(L2 모델에는 없음). 검증 연도의 처음 보는 발전소가 가려 왔다. 사후 배율은 최근 두 해 −1.5 / −1.4% 지만 2022-23 +0.6% 라 지금 규칙으로는 불통과 → L2 구성원 추가가 다음 시험. 출력제어는 실재·급증하지만 2024-25 상한 −0.5% 로 작고, 평가 기간 출처 어긋남(2025-06 ~ 12)은 규정 §6 때문에 쓸 수 없다.

**실측 기상·B 강수 8열** (§9): 실측은 규정 §6 으로 입력 불가(학습 보조 시도는 모두 기각). B 강수 8열의 빈칸은 2021-11-29 하루뿐이고 10시 발행분으로 채워져 영향이 없다. 안 쓰는 이유는 정보량(중복·거의 0·순열 중요도 엇갈림)이다.

## 2. 근거 강도 표기

| 표기 | 뜻 |
|---|---|
| **규정** | 대회 규정 때문에 쓰거나 못 쓴다. 성능 근거와 무관 |
| **사실** | 데이터나 수식으로 확정된다(값이 같다, 한쪽이 다른 쪽의 단조 변환이다) |
| **강** | 다시 학습해 세 해 모두 개선 + 다른 시드로 재현, 또는 리더보드로 확인 |
| **중** | 다시 학습해 세 해 모두 같은 방향(재현 없음), 또는 중요도가 크고 일관됨 |
| **약** | 결과가 섞이거나 잡음(±0.3%) 범위, 또는 통계·스크리닝만 하고 다시 학습은 안 함 |
| **없음** | 관례·임의로 정했거나 시험하지 않음 |

근거 자료의 종류
- **F2 통계**(`docs/변수사전.md`): CSI 와의 순위상관 ρ, 20구간 설명력 η², 운량·습도로 설명한 뒤 남은 설명력(추가 η²), 예보 정확도. 다시 학습한 것이 아니다.
- **F2 모델 기여**: E2-final 모델에서 피처 하나를 섞었을 때의 벌금 변화, **2024-25 한 해만**.
- **F9 순열 중요도**(`docs/피처_분석.md`): E9 LightGBM, 세 해 fold 평균. 판정에 쓴 것과 **같은 세 해**에서 계산했다(§6.2 의 선택 낙관).
- **재학습**: 그 피처를 넣고/빼고 다시 학습해 세 해 비교. 가장 직접적인 근거.

## 3. 원 피처를 그대로 쓴 것 (18열)

"그대로"의 뜻: 값은 바꾸지 않았다. 대회가 붙여 준 예보 지점으로 붙였고(`build_base.py`), 한 발행분만 빠진 (지점, 시각)은 같은 지점·시각의 다른 발행분 값으로 채웠다(규정 §6 이 허용한 "같은 날 다른 발행분", 평가 A 264행). 단위 통일·이상값 처리는 하지 않았다 — 트리 모델은 값의 순서로만 나누므로 필요 없고, 범위 밖 값은 0.006% 이하다(F6).

## 6. 근거의 질 — 가로질러 본 문제

### 6.1 "기각"의 대부분은 "효과를 확인 못 함"이다

판정 규칙("세 해 모두 개선 + 시드 재현")은 거짓 채택을 막는 데는 좋지만, 효과가 잡음(±0.3%)보다 작은 피처는 원리상 통과하지 못한다. 그래서 §5.4 의 목록은 **"해롭다"의 근거가 아니라 "쓸 근거가 없다"** 다.
해롭다는 근거가 분명한 것은 §5.3 의 몇 개(E3, X07, M1 그리고 검증 연도 조건의 ID 범주형)뿐이다. 남은 기간에 이 목록을 다시 넣어 볼 가치는 낮다 — 넣어도 잡음 수준일 것이기 때문이다.

### 6.2 V07 은 시드 재현에 실패한다 (새로 확인)

V07(V05 기여 없는 11개 + V06 중복 6개 빼기)은 지금 모든 구성원의 바탕이다. 문서에는 "통과"로만 남아 있고, 시드 재현 비교는 한 적이 없었다. 재현용 예측(`V07s2x2`)은 11/10 설정값 실험 때 이미 만들어져 있어서 비교만 했다.

| 비교 | 2024-25 | 2023-24 | 2022-23 | 규칙 |
|---|---:|---:|---:|---|
| V07x2 vs E9-00x2 (시드 0·1, 원래 판정) | −0.76% | −1.34% | −0.40% | 통과 |
| **V07s2x2 vs E9-00s2x2 (시드 2·3)** | −0.26% | −0.96% | **+0.45%** | **재현 실패** |

```
python src_tools/compare_years.py E9-00s2x2 V07s2x2
```

해석
- 2023-24 의 약 −1% 는 두 번 다 나와서 실제일 수 있다. 2024-25·2022-23 은 잡음 범위다.
- V05 에서 뺄 피처를 고른 순열 중요도는 판정과 **같은 세 해**에서 계산했다 → 고른 결과가 같은 세 해에서 좋아 보이는 것은 어느 정도 당연하다(선택 낙관).
- V06 은 단독으로 기각(+0.27 / −0.21 / −0.01%)이었는데 V05 와 합친 V07 이 통과해서 들어갔다. V07 − V05 차이는 −0.43 / −0.05 / −0.17%p 로 잡음 범위 → V06 부분에는 성능 근거가 없다(중복이라는 사실 근거만 있다).
- **결론**: 17개를 뺀 결정은 "빼도 손해가 없다" 수준이고, 피처를 단순하게 만든 이점은 있다. 다시 넣을 이유도 없다(넣어도 잡음). 다만 기록(`docs/피처_분석.md` §8)의 "통과"는 "재현 실패, 중립"으로 고쳐야 한다.
- V07 다음 단계인 G2(GFS)는 V07 과 합친 상태로 재현이 통과했으므로(E10-00s2x2 −2.13 / −7.22 / −3.35%) 지금 구성원의 성능 근거에는 문제가 없다.
- XGBoost 쪽도 같다. V07 은 LightGBM 중요도로 고른 것이라 XGBoost CSI 에서 빼지 않은 판(E10-12b)을 따로 돌렸는데, 뺀 판(E10-12) 대비 −0.81 / +0.94 / −0.74% 로 섞였다 → XGBoost 에서도 V07 은 중립.

### 6.3 범주형 ID 기각은 '처음 보는 발전소' 때문이었다 (새로 확인)

검증 연도마다 직전 2년 학습 기간에 없던 발전소가 많다. 실제 평가 기간에는 **0%** 다(모든 발전소 이력 158일 이상).

| 검증 연도 | 처음 보는 발전소 | 그 행 비율 |
|---|---:|---:|
| 2024-25 | 48곳 | 17.3% |
| 2023-24 | 99곳 | 25.9% |
| 2022-23 | 61곳 | 41.8% |

그래서 "학습 때 본 발전소는 실험 예측, 처음 보는 발전소는 기준 예측"으로 섞어 다시 채점했다(`analysis_lab/F10_본발전소_분리.py`, 참조 구성).

| 실험 (기준) | 전체(원래 판정) | 본 발전소만 바꿈 |
|---|---|---|
| V02 발전소 ID 범주형 (E9-00x2) | +0.52 / **+10.34** / −1.13% | **−1.73 / −0.31 / −0.69%** |
| V03 예보 지점 ID 범주형 (E9-00x2) | +0.63 / **+8.11** / −1.78% | −0.45 / −0.22 / −0.76% |
| X12 지점 거리·번호 (E7-00x2) | −0.40 / +1.92 / −1.87% | −0.35 / −0.22 / −0.53% |
| *대조군* 시드만 바꿈 E9-00s2x2 (E9-00x2) | −0.24 / −0.50 / −0.42% | −0.34 / −0.06 / −0.33% |
| *대조군* 공휴일 X17 (E7-00x2) | +0.45 / −0.09 / +0.90% | +0.23 / −0.03 / +0.39% |
| *반례* 발전소 맑은날 기준값 E3 (E2-finalx2) | −1.25 / +0.42 / +0.32% | −1.73 / −0.64 / −0.28% → **리더보드 약 300만 원 손해** |

```
python analysis_lab/F10_본발전소_분리.py E9-00x2 V02x2 V03x2 E9-00s2x2
python analysis_lab/F10_본발전소_분리.py E7-00x2 X12x2 X17x2
python analysis_lab/F10_본발전소_분리.py E2-finalx2 E3-finalx2
```

해석
- V02·V03·X12 의 2023-24 손해(+2 ~ +10%)는 거의 전부 처음 보는 발전소에서 나왔다. **"발전소 ID 를 넣으면 나빠진다"는 기각 근거는 실제 평가 조건으로 옮겨지지 않는다.**
- 그렇다고 넣으면 좋아진다는 근거도 약하다. 시드만 바꾼 대조군도 이렇게 나누면 세 해 다 음수(−0.34 / −0.06 / −0.33%)다. V03·X12 는 이 잡음 폭과 비슷하다. V02 의 2024-25 −1.73% 만 잡음보다 뚜렷하다.
- 공휴일(X17)은 나눠도 여전히 나빠서, 이 나누기가 아무 실험이나 통과시키는 착시는 아니다.
- **가장 중요한 반례는 E3 다.** 발전소별 이력으로 만든 값이라 V02 와 성격이 같고, 본 발전소만 보면 세 해 다 좋아지는데, 처음 보는 발전소가 없는 실제 평가 기간(리더보드)에서 약 300만 원 손해였다. 발전소의 과거 모습(설비 변경·장기 정지 등)이 1년 뒤에는 달라질 수 있다는 뜻으로 읽힌다.
- 이 분석은 결과를 본 뒤 만든 나누기이고, GFS 가 없는 옛 기준(E9-00, E7-00) 위의 결과다.
- 더 넓게 보면: **검증 설계가 실제 평가보다 '새 발전소 일반화'를 훨씬 더 요구한다.** 발전소 정체성을 쓰는 피처는 검증에서 불리하게, 위경도처럼 일반화되는 피처는 유리하게 평가되어 왔다. 2023-24 는 처음 보는 발전소가 99곳으로 가장 많으므로, 다른 실험에서 2023-24 만 크게 흔들린 경우에도 이 영향을 의심해 볼 수 있다(확인은 안 함).

### 6.4 같은 변수에 대한 판단이 기준 모델에 따라 뒤집혔다

두 경우 모두 앞뒤 결과가 섞여 있다 → 이 변수들은 있어도 없어도 같다는 뜻이다. 어느 쪽으로 정했든 근거가 약하다는 점은 같다.

## 7. 서로 바꿀 후보 — 그대로 ↔ 가공 ↔ 기각

근거가 약한 결정마다 "다른 처리로 바꿀 여지가 있는가"를 두 가지로 따졌다.
- (a) 지금 처리의 근거가 **약·없음** 인가.
- (b) 바꾼 처리가 잡음(해마다 ±0.3%)을 넘을 **구체적인 이유**가 있는가.

근거가 약한 결정은 대부분 (b)에서 걸린다. 근거가 약한 이유가 바로 효과가 0 근처라는 데 있기 때문이다. 이런 것은 어느 쪽으로 바꿔도 잡음이라 바꿀 가치가 없다(§7.2).
(a)와 (b)를 모두 만족하는 것은 아래 네 개뿐이고, 셋은 **가공 방식**의 문제다.

### 8.1 L1 손실의 묶음 합 치우침 — 가장 유력

**현상**: 실제 평가 기간처럼 **학습 때 본 발전소만으로 묶음을 만들면**, 세 해 모두 예측을 낮추는 쪽이 낫다(최적 배율 0.985 / 0.980 / 0.995). 본 발전소의 11 ~ 15시 예측÷실적은 이력 길이와 관계없이 1.017 ~ 1.042 다.

**메커니즘 확인** (2024-25, 본 발전소만, 다른 설정은 같고 손실만 다른 두 모델)

| 모델 | 손실 | 한낮 예측÷실적 | 최적 배율 | 운량 ≤10 / 11 ~ 50 / 51 ~ 89 / ≥90 |
|---|---|---:|---|---|
| E4-00 | L2 (평균) | 0.997 | 1.01 (−0.41%) | 1.001 / 0.983 / 0.991 / 1.007 |
| E4-02 | L1 (중앙값) | 1.020 | 0.98 (−1.06%) | 1.034 / 1.033 / 1.024 / 0.988 |
| E11-10T1 (지금 앙상블) | L1 | 1.019 | 0.98 (−1.83%) | 1.029 / 1.035 / 1.035 / 0.983 |
| S2T1 (GFS 전용) | L1 | 1.030 | 0.97 (−3.15%) | 1.024 / 1.034 / 1.058 / 1.017 |

발전소별 L1 은 그 조건에서의 **중앙값**을 맞힌다. 맑음 쪽 예보에서는 "갑자기 구름이 끼는" 쪽으로 꼬리가 길어 중앙값 > 평균 → 과대, 흐림 예보에서는 "개는" 쪽으로 꼬리가 길어 중앙값 < 평균 → 과소. 벌금은 묶음 합에 매기므로 발전소별 오차가 서로 독립이면 평균 합이, 완전히 같이 움직이면 중앙값 합이 맞다. 실제는 그 사이라 L1 은 과대, L2 는 거의 치우침이 없다. 운량별 모양이 정확히 이 설명대로 나온다.

**왜 지금까지 안 보였나**: 검증 연도의 처음 보는 발전소는 오히려 과소 예측된다(0.974 ~ 1.014). 같은 묶음 안에서 둘이 상쇄되어 전체 배율이 해마다 0.975 / 0.990 / 1.015 로 달라 보였고, 그래서 "α 는 1.0 유지"로 정했다(F4). §6.3 과 같은 가림막이다. 실제 평가 기간에는 처음 보는 발전소가 없다.

**사후 배율 시험** (F12, 결과를 보기 전에 정한 규칙: 배율은 남은 두 해에서 정해 그해에 적용, 본 발전소만)

| 방식 | 2024-25 | 2023-24 | 2022-23 | 판정 |
|---|---:|---:|---:|---|
| 하나의 배율 (참조 구성) | −1.53% (0.99) | −1.39% (0.99) | **+0.59%** (0.98) | 불통과 |
| 하나의 배율 (제출 구성 E11-10T1x2.csv) | −1.51% | −1.50% | **+0.66%** | 불통과 |
| 운량 구간별 배율 3개 | −1.68% | −2.18% | **+1.15%** | 불통과 |
| (참고) 세 해 모두로 정한 하나의 배율 0.98 | −1.83% | −1.89% | +0.59% | 낙관치 |

해석
- 최근 두 해는 다른 해에서 정한 배율로도 1.4 ~ 1.5% 씩 준다. 2022-23 만 치우침이 거의 없다(그해 최적 0.995, −0.13%).
- 2022-23 은 학습 기간이 1.4년뿐이고 발전소가 적으며, B 예보의 습도–운량 관계가 2023 중반에 바뀌기 전 구간이다(§8.4). 지금 평가 모델(2023-06 ~ 2025-05 학습)은 최근 두 해와 조건이 같다. 하지만 이것을 이유로 2022-23 을 판정에서 빼는 것은 **판정 규칙 변경이라 사용자 결정**이다.
- 배율 하나로 고치면 흐림 쪽 과소는 더 나빠진다. 원인이 손실이므로 **모델 단계에서 고치는 쪽이 근본적**이다: L2(또는 Huber) 구성원을 더하거나 L1·L2 를 섞기. 흐림 쪽까지 같이 고쳐지므로 2022-23 에서도 손해가 없을 수 있다(미시험). V07T1·S2T1 의 L2 판은 판마다 세 해 약 25분 + 재현 25분.
- 배율·비중을 리더보드로 맞추는 것은 규정 §2 위반이다. 여기 숫자는 모두 학습 기간 검증에서 나왔다.
- 근거의 한계: E3 는 본 발전소만 보면 좋아졌지만 리더보드에서 졌다(§6.3). 이번 것은 메커니즘이 확인됐다는 점이 다르지만, 리더보드로 옮겨진다는 보장은 없다.

### 8.2 출력제어 — 실재하고 급증하지만, 우리 벌금에서는 아직 작다

- **외부 자료**: 육지 출력제어량 2023년 0.3GWh → 2024년 13.2GWh → **2025년 상반기 164GWh**([경향신문](https://www.khan.co.kr/article/202509161530021/)). 호남 횟수 2024년 26 ~ 27회 → 2025년 10월까지 56회, 2025년 영남·영동·충청으로 확대([해줌 정리](https://blog.haezoom.com/insight_vpp_36/) 등 2차 자료, 공식 원자료로는 확인 안 함).
- **우리 자료**(맑은 한낮, 예측÷실적): 2024-25 봄 휴일 **1.060** vs 봄 평일 1.014, 남서 지역(위도 < 36°, 경도 < 127.6°) **1.062** vs 그 밖 1.026. 봄 휴일 가운데 한낮을 15% 넘게 과대 예측한 날 39%(봄 평일 7%). 2023-24·2022-23 에는 이 모양이 없다 → 외부 자료의 급증 시점과 맞다.
- **크기**: 2024-25 에서 봄 휴일 한낮만 그해에서 고른 배율(0.96)로 고쳐도 −0.48%(낙관 상한). 제어가 특정 날에 몰려 있고, 휴일 한낮 SMP 가 평일보다 약 25% 낮아(2025 봄 108원 vs 136원) 벌금 가중도 작다.
- **검증 구조의 한계**: "세 해 모두 개선" 관문은 출력제어가 없던 해에서도 좋아지기를 요구하므로, **최근에 생긴 원인은 원리상 통과할 수 없다**. 요일·공휴일은 규정 §4 로 쓸 수 있고(출력제어 안내 글은 §8 로 불가), 평가 모델의 학습 기간(2023-06 ~ 2025-05)에는 2025 봄 제어가 들어 있다. 과거 공휴일 피처(X17)는 제어가 거의 없던 학습 기간에서 시험한 것이다.
- **평가 기간 전망**: 2025-06 ~ 2026-05 는 2025 추석 연휴(7일)와 2026 봄을 포함해 더 클 가능성이 높다. 그래도 2024-25 상한이 0.5% 라, 규모가 2 ~ 3배여도 1 ~ 2% 안팎이다. 검증할 방법이 없어 넣을지는 사용자 판단이다.

### 8.3 평가 기간의 출처 어긋남 — 기압과 같은 방법으로 잡히지만 원인을 모름

출처 전용 모델끼리(GFS 전용 S2T1, GEFS 전용 S3, 지역 예보 전용 V07T1) 11 ~ 15시 하루 예측 비율의 월별 중앙값을 검증 세 해와 평가 기간에서 비교했다. 한 출처의 값 정의가 바뀌면 그 출처만 쓴 모델이 따로 움직인다.

- **양성 대조(방법 확인)**: A 기압은 V07T1 에만 들어간다. 2026-03 ~ 05 의 GFS 전용 ÷ 지역 예보 전용이 검증 평균보다 **+3.0 / +4.5 / +3.5%**(검증 범위 밖), GEFS 쪽은 +5.5 / +4.6 / +4.3%. 이미 아는 기압 정의 변경을 그대로 잡았다.
- **새로 잡힌 것**: 2025-06 ~ 12 에 GFS 전용 ÷ 지역 예보 전용이 −3.7 / −2.7 / −4.1 / −5.2 / −7.4 / +0.2 / −5.8%(7달 중 5달 검증 범위 밖). GEFS 전용도 같은 방향이다(9월 −7.9%, z −11). GEFS ÷ GFS 는 범위 안이다 → **NOAA 두 출처가 함께 지역 예보와 어긋난다.**
- **정의 변경인가 — 아닌 것으로 본다**: 입력 단계에서 지역 예보(A·B 운량·습도·자외선)와 GFS 의 관계, A·B 사이의 관계는 평가 기간에 계단 변화가 없다(z 대부분 ±2 안, 학습/평가 파일 경계 2025-06-01 에서 끊기지 않음). GFS·GEFS 입력의 월 평균도 일사량과 운량이 반대로 움직여 날씨로 설명된다. 기압처럼 한 출처만 계속 한쪽에 붙어 있는 모양이 아니다. 2025 여름 기록적 더위 같은 날씨 국면에서 두 계열 예보가 다르게 반응했을 가능성이 크다(확인은 안 됨).
- **쓸 수 있나 — 없다**: 평가 기간 자료로 찾은 것이라 이걸 보고 비중·규칙을 바꾸면 규정 §6 에 걸린다(기압과 같은 처지). 어느 쪽이 맞는지도 알 방법이 없다(평가 기간 실적 없음, 리더보드로 고르면 §2 위반). 같은 비중 앙상블이 이미 두 쪽을 섞고 있다는 것만 확인했다.

### 8.4 B 습도 예보가 해마다 흘러간다 — 작음

- 하루 평균 A 습도와 B 습도의 관계(월별로 맞춘 잔차의 해 평균): +2.2(2021-22) → +0.2 → −1.0 → −1.3 → **−2.4(평가 기간)**. 계단이 아니라 느린 흐름이다.
- 학습 기간 실측과 비교하면 흘러가는 쪽은 **B** 다. A 습도 예보의 치우침은 2021-22 이후 0 근처에서 안정적이다(+0.2 / +0.2 / −0.2 / +0.1). B 습도 예보는 한낮 기준 −5.7 → −4.7 → −2.4 → −0.5 로 해마다 습해진다(B 기온 예보 치우침은 안정적).
- 영향은 작다고 본다. B 습도는 순열 중요도 +2.1% 의 보조 변수이고, 방향(B 가 습해지면 예측이 낮아짐)이 §8.3 어긋남과 반대다.
- 덤으로 찾은 것: B 의 습도–운량 관계가 2022-23 → 2023-24 사이에 크게 뛰었다(잔차 −2.6 → +3.4). 2022-23 검증 연도가 다른 두 해와 자주 다르게 나오는 이유의 후보다(확인 안 함).

### 8.5 그 밖

- **GFS·GEFS 입력의 정의 변경**: 평가 기간 월 평균 z 가 ±3 안에서 날씨와 함께 움직인다(6월 흐림, 7·11·1월 맑음). 기압처럼 특정 달부터 한쪽에 붙는(z −8 ~ −18) 모양이 없다.
- **1 ~ 2월 과대 예측**(1월 예측÷실적 2024-25 1.093, 2023-24 1.043, 2022-23 0.949): 눈 덮임으로 보이지만 해마다 방향이 다르고 피처 세 형태가 실패했다(§5.4).

### 8.6 결론

- 기압 같은 "새로운 체계적 원인"을 하나 꼽으면 **L1 손실의 묶음 합 치우침**이다. 데이터 정의 문제가 아니라 우리 손실 선택이 만든 것이고, 검증 설계(처음 보는 발전소)가 가려 왔다. 크기는 최근 두 해 −1.4 ~ −1.5%/해, 2022-23 은 0.
- 사후 배율로는 지금 규칙을 통과하지 못한다. 다음 단계는 **L2 구성원을 더한 앙상블**을 지금 규칙 그대로 시험하는 것이다(흐림 쪽 과소도 같이 고쳐져 2022-23 에서 통과할 여지가 있음).
- 출력제어는 실재하지만 지금 자료로는 크기가 작고 검증할 수 없다. 출처 어긋남은 규정상 쓸 수 없다.
- 기대치: 리더보드 환산(내부 1% ≈ 86 ~ 218만 원, 제출 두 번에서 얻은 약한 근거)으로 −1.5% 면 약 130 ~ 330만 원이다. 5위(1,251만 원 차)를 이것 하나로 따라잡기는 어렵다.
- **11/11 17시 갱신 — §10.1**: 다른 세션에서 채택한 추세 보정(`src_tools/trend_fix.py`)이 이 수준 치우침을 이미 흡수한다. 추세 보정 뒤에는 남은 수준 치우침이 0 이므로 배율 0.99 를 겹쳐 쓰면 안 된다.

## 9. 실측 기상과 B 예보 강수 8열을 안 쓰는 이유

### 9.1 실측 기상 (`observed_wa`, `observed_wb`)

- **입력으로는 규정상 불가**: 규정 §6 "학습 기간에 제공된 실측 기상은 학습 단계의 보조로만 쓸 수 있다. 평가 입력에는 넣지 않는다." 평가 구간에는 실측 파일 자체가 없다.
- **학습 보조로는 시험했고 모두 기각**: 예보 보정 MOS — 지점 × 시각 치우침 빼기(X16 −0.47 / −0.49 / +0.42%), 운량 구간 → 실측 평균(X16b +0.10 / +0.91 / −0.61%), 보정 예보로 하루 평균(X16c −0.03 / +0.29 / +0.93%). 실측(자외선·운량)을 먼저 맞히는 보조 모델(A1 −0.20 / +0.75 / −0.03%). 결과가 섞였다 → "효과 없음".
- **진단에는 쓴다**: 예보가 잃는 정보의 상한(F2), 예보 치우침의 해별 흐름(§8.4).

### 9.2 B 예보 강수 8열 — 빈칸은 이유가 아니다

빈칸의 실체: 학습 구간 1,298행은 **2021-11-29 하루, 17시 발행분, 73개 지점 전부**이고 8열이 같은 행에서 함께 비어 있다. `build_base.py` 가 같은 지점·시각의 10시 발행분 값으로 채운다(규정 §6 이 허용한 "같은 날 다른 발행분", 학습·평가에 같은 규칙). 지금 평가 모델의 학습 기간(2023-06 ~ 2025-05) 밖이고, 평가 구간에는 빈칸이 없다. 따라서 빈칸은 모델에 아무 영향이 없다.

안 쓰는 진짜 이유는 열마다 다르다.

| 열 | 안 쓰는 이유 | 근거 강도 |
|---|---|---|
| `wb_precip_prob` 강수확률 | baseline 에 있던 열. 혼자선 η² 0.241 로 강하지만 운량·습도와 겹침(추가 η² 0.013). 순열 중요도가 해마다 엇갈려(−0.79 / −0.52 / +1.44%) V05 로 뺌 | 약(V07 재현 실패, §6.2) |
| `wb_total_liq` 총강수 | baseline 에 있던 열. 시각 단위 예보 정확도 0.32, η² 0.051. V05 로 뺌. 하루 합(`wx_day_rain`)·전날 합(`wx_prev_rain`)도 V05 로 같이 뺌 | 약 |
| `wb_rain_prob`, `wb_rain` | 위 두 열과 사실상 같은 값(ρ 0.991, 0.994) | 사실 |
| `wb_snow` | 99.7% 가 0, η² 0. 강설 피처 세 형태(X01·X05·X19) 실패 | 약 |
| `wb_snow_prob`, `wb_ice_prob`, `wb_ice` | 98 ~ 99.9% 가 0, η² 0. **다시 학습해 본 적 없음**(통계만) | 약 |

지금 강수 정보는 **A 강우**(시각 값 두 발행분 + 그날·전날 하루 합)로만 들어간다. B 강수를 뺀 V07 이 "빼도 같다" 수준(§6.2)이라 다시 넣을 이유도 약하다. 강수 열이 정보를 가장 많이 잃는 변수(실측 η² 0.291 → 예보 0.051)라는 점도, 예보 품질이 낮다는 뜻이지 가공으로 되살릴 정보가 있다는 뜻은 아니다.

### 10.1 기록 시점의 상태 (다른 세션 작업 반영)

- 최고 제출 **E12-10cftx2_comp 6,463,384,705**(빠짐 처리 버그 수정 + 일출·일몰 보정). A 기압을 뺀 판은 리더보드 −254만 원 → 기압 유지.

### A. 시각 평활 — 최근 두 해는 줄지만 지금 규칙으로는 불통과

**근거**: 벌금의 약 55% 가 하루 안 시각 배분 오차다(F13a). 구름이 오는 시각을 한두 시간 틀리는 것이 원인이면, 시각 단위로 날카로운 예측을 앞뒤 시각과 섞어 부드럽게 하는 것만으로 기대 오차가 준다.
**방법**: 묶음 예측 ÷ 묶음 청천 기준(Σ 용량 × Haurwitz 청천)을 같은 날 안에서 (w, 1 − 2w, w) 로 섞은 뒤 청천 기준을 다시 곱한다. 해 뜰 녘·질 녘(청천 기준이 그날 최대의 5% 미만)은 이웃으로 쓰지 않는다.

| w | 2024-25 | 2023-24 | 2022-23 |
|---|---:|---:|---:|
| 0.05 | −0.23% | −0.17% | +0.04% |
| 0.10 | −0.61% | −0.44% | −0.05% |
| 0.15 | −0.91% | −0.64% | −0.05% |
| 0.20 | −1.13% | −0.76% | +0.03% |
| 0.25 | −1.25% | −0.81% | +0.17% |
| 0.30 | −1.27% | −0.80% | +0.37% |

- 한 해 빼고 정한 w(미리 정한 규칙): 2024-25 w 0.20 → −1.13%, 2023-24 w 0.20 → −0.76%, 2022-23 w 0.30 → **+0.37%** → **불통과**.
- w 0.10 ~ 0.15 는 세 해 모두 줄지만, 결과를 본 뒤 고른 값이라 근거로 쓸 수 없다.
- 해석: 모델의 시각별 모양이 실제 시각 불확실성보다 날카롭다는 신호다. 다시 "최근 두 해는 좋고 2022-23 은 아님" 모양이다(§8.1 L1 치우침, 추세 보정과 같음).

### 12.4 k-fold 로 평가 기간 정보를 쓸 수 있나

- **평가 기간 안에서 k-fold(무작위든 구간이든)는 안 된다.** 어떤 날을 예측할 때 그보다 뒤 날짜의 평가 기간 입력이 학습에 들어가므로, "평가 기간 전체를 미리 모아 쓰는 것"(§6)이 된다.
- **되는 것은 앞으로만 늘려 가는 방식**(1 ~ 5월을 6월 예측에 쓰는 식)이다. 이것을 검증하려면 같은 절차를 검증 세 해에 똑같이 재현해야 한다(검증 연도가 평가 기간 역할). 그런데 달마다 다시 학습하면 한 해에 12번, 세 해면 36번이라 마감 전에는 불가능하다.
- **기대도 낮다.** 평가 기간 입력에서 크게 바뀐 것은 A 기압 하나인데, 그 변화를 없앤 판(기압 뺀 판)이 리더보드에서 −254만 원이었다. 입력 분포에 맞추는 방향은 오히려 손해일 가능성이 크다. 나머지 변화는 날씨(GFS·GEFS)이거나 작다(B 습도 흐름, §8.4).
- **학습 기간 안의 k-fold 는 가능하다.** 예를 들어 2024-25 를 계절별로 나눠 다른 기간 전부로 학습하는 식이다. 규정 문제는 없고(정답이 있는 기간), 판정을 평가 기간과 비슷한 최근 조건에 가깝게 만든다. 다만 학습에 검증보다 뒤 기간이 들어가 낙관적이 되고, 판정 규칙을 바꾸는 일이라 **사용자 결정**이다.
