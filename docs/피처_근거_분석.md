**규모**

규정·데이터 사실로 확정된 결정도 따로 근거가 필요 없다(기온 최고·최저 제외, 실측·SMP 제외, cos 천정각 중복).

**근거가 약하거나 없는 결정**
- **원 변수 목록의 출발점은 운영진 baseline.py 의 15개**다. 나중에 통계(F2)와 추가 실험(X01)으로 뒷받침했지만, 남은 변수 하나하나를 빼 보는 시험은 대부분 안 했다(B 운량·B 기온 등).
- **V07(피처 17개 빼기)은 시드 재현에 실패한다(새로 확인, §6.2).** 지금 모든 구성원의 바탕인데, "빼서 좋아졌다"가 아니라 "빼도 같다" 수준이다.
- 같은 변수에 대한 판단이 기준 모델에 따라 뒤집혔다(풍속·강수확률, 전날 요약) → 이 변수들은 효과가 0 근처라는 뜻(§6.4).
- GFS 일사량의 3시간 → 1시간 배분, 고정 상자 범위·1° 크기, GEFS 표준편차 배분은 따로 비교한 적이 없다(§6.5).

**새로 확인한 것 중 가장 중요한 것** (§6.3)
발전소 ID·예보 지점 ID 범주형(V02·V03)과 지점 거리·번호(X12)를 기각한 근거(2023-24 에서 +8 ~ +10%)는 **검증 연도에만 있는 '처음 보는 발전소'** 에서 나온 것이었다. 실제 평가 기간에는 처음 보는 발전소가 0% 다.
학습 때 본 발전소만 실험 예측으로 바꾸면 세 경우 모두 세 해 다 벌금이 줄었다(V02 −1.73 / −0.31 / −0.69%). 다만 같은 성격의 E3(발전소별 맑은날 기준값)도 이렇게 보면 좋아지는데 리더보드에서는 약 300만 원 손해였으므로, 이것만으로 채택할 근거는 못 된다.

## 2. 근거 강도 표기

| 표기 | 뜻 |
|---|---|
| **규정** | 대회 규정 때문에 쓰거나 못 쓴다. 성능 근거와 무관 |
| **사실** | 데이터나 수식으로 확정된다(값이 같다, 한쪽이 다른 쪽의 단조 변환이다) |
| **강** | 다시 학습해 세 해 모두 개선 + 다른 시드로 재현, 또는 리더보드로 확인 |
| **중** | 다시 학습해 세 해 모두 같은 방향(재현 없음), 또는 중요도가 크고 일관됨 |
| **약** | 결과가 섞이거나 잡음(±0.3%) 범위, 또는 통계·스크리닝만 하고 다시 학습은 안 함 |
| **없음** | 관례·임의로 정했거나 시험하지 않음 |

근거 자료의 종류
- **F2 통계**(`docs/변수사전.md`): CSI 와의 순위상관 ρ, 20구간 설명력 η², 운량·습도로 설명한 뒤 남은 설명력(추가 η²), 예보 정확도. 다시 학습한 것이 아니다.
- **F2 모델 기여**: E2-final 모델에서 피처 하나를 섞었을 때의 벌금 변화, **2024-25 한 해만**.
- **F9 순열 중요도**(`docs/피처_분석.md`): E9 LightGBM, 세 해 fold 평균. 판정에 쓴 것과 **같은 세 해**에서 계산했다(§6.2 의 선택 낙관).
- **재학습**: 그 피처를 넣고/빼고 다시 학습해 세 해 비교. 가장 직접적인 근거.

## 3. 원 피처를 그대로 쓴 것 (18열)

## 6. 근거의 질 — 가로질러 본 문제

### 6.1 "기각"의 대부분은 "효과를 확인 못 함"이다

판정 규칙("세 해 모두 개선 + 시드 재현")은 거짓 채택을 막는 데는 좋지만, 효과가 잡음(±0.3%)보다 작은 피처는 원리상 통과하지 못한다. 그래서 §5.4 의 목록은 **"해롭다"의 근거가 아니라 "쓸 근거가 없다"** 다.
해롭다는 근거가 분명한 것은 §5.3 의 몇 개(E3, X07, M1 그리고 검증 연도 조건의 ID 범주형)뿐이다. 남은 기간에 이 목록을 다시 넣어 볼 가치는 낮다 — 넣어도 잡음 수준일 것이기 때문이다.

### 6.2 V07 은 시드 재현에 실패한다 (새로 확인)

V07(V05 기여 없는 11개 + V06 중복 6개 빼기)은 지금 모든 구성원의 바탕이다. 문서에는 "통과"로만 남아 있고, 시드 재현 비교는 한 적이 없었다. 재현용 예측(`V07s2x2`)은 11/10 설정값 실험 때 이미 만들어져 있어서 비교만 했다.

| 비교 | 2024-25 | 2023-24 | 2022-23 | 규칙 |
|---|---:|---:|---:|---|
| V07x2 vs E9-00x2 (시드 0·1, 원래 판정) | −0.76% | −1.34% | −0.40% | 통과 |
| **V07s2x2 vs E9-00s2x2 (시드 2·3)** | −0.26% | −0.96% | **+0.45%** | **재현 실패** |

```
python src_tools/compare_years.py E9-00s2x2 V07s2x2
```

해석
- 2023-24 의 약 −1% 는 두 번 다 나와서 실제일 수 있다. 2024-25·2022-23 은 잡음 범위다.
- V05 에서 뺄 피처를 고른 순열 중요도는 판정과 **같은 세 해**에서 계산했다 → 고른 결과가 같은 세 해에서 좋아 보이는 것은 어느 정도 당연하다(선택 낙관).
- V06 은 단독으로 기각(+0.27 / −0.21 / −0.01%)이었는데 V05 와 합친 V07 이 통과해서 들어갔다. V07 − V05 차이는 −0.43 / −0.05 / −0.17%p 로 잡음 범위 → V06 부분에는 성능 근거가 없다(중복이라는 사실 근거만 있다).
- **결론**: 17개를 뺀 결정은 "빼도 손해가 없다" 수준이고, 피처를 단순하게 만든 이점은 있다. 다시 넣을 이유도 없다(넣어도 잡음). 다만 기록(`docs/피처_분석.md` §8)의 "통과"는 "재현 실패, 중립"으로 고쳐야 한다.
- V07 다음 단계인 G2(GFS)는 V07 과 합친 상태로 재현이 통과했으므로(E10-00s2x2 −2.13 / −7.22 / −3.35%) 지금 구성원의 성능 근거에는 문제가 없다.

### 6.3 범주형 ID 기각은 '처음 보는 발전소' 때문이었다 (새로 확인)

검증 연도마다 직전 2년 학습 기간에 없던 발전소가 많다. 실제 평가 기간에는 **0%** 다(모든 발전소 이력 158일 이상).

| 검증 연도 | 처음 보는 발전소 | 그 행 비율 |
|---|---:|---:|
| 2024-25 | 48곳 | 17.3% |
| 2023-24 | 99곳 | 25.9% |
| 2022-23 | 61곳 | 41.8% |

그래서 "학습 때 본 발전소는 실험 예측, 처음 보는 발전소는 기준 예측"으로 섞어 다시 채점했다(`analysis_lab/F10_본발전소_분리.py`, 참조 구성).

| 실험 (기준) | 전체(원래 판정) | 본 발전소만 바꿈 |
|---|---|---|
| V02 발전소 ID 범주형 (E9-00x2) | +0.52 / **+10.34** / −1.13% | **−1.73 / −0.31 / −0.69%** |
| V03 예보 지점 ID 범주형 (E9-00x2) | +0.63 / **+8.11** / −1.78% | −0.45 / −0.22 / −0.76% |
| X12 지점 거리·번호 (E7-00x2) | −0.40 / +1.92 / −1.87% | −0.35 / −0.22 / −0.53% |
| *대조군* 시드만 바꿈 E9-00s2x2 (E9-00x2) | −0.24 / −0.50 / −0.42% | −0.34 / −0.06 / −0.33% |
| *대조군* 공휴일 X17 (E7-00x2) | +0.45 / −0.09 / +0.90% | +0.23 / −0.03 / +0.39% |
| *반례* 발전소 맑은날 기준값 E3 (E2-finalx2) | −1.25 / +0.42 / +0.32% | −1.73 / −0.64 / −0.28% → **리더보드 약 300만 원 손해** |

```
python analysis_lab/F10_본발전소_분리.py E9-00x2 V02x2 V03x2 E9-00s2x2
python analysis_lab/F10_본발전소_분리.py E7-00x2 X12x2 X17x2
python analysis_lab/F10_본발전소_분리.py E2-finalx2 E3-finalx2
```

해석
- V02·V03·X12 의 2023-24 손해(+2 ~ +10%)는 거의 전부 처음 보는 발전소에서 나왔다. **"발전소 ID 를 넣으면 나빠진다"는 기각 근거는 실제 평가 조건으로 옮겨지지 않는다.**
- 그렇다고 넣으면 좋아진다는 근거도 약하다. 시드만 바꾼 대조군도 이렇게 나누면 세 해 다 음수(−0.34 / −0.06 / −0.33%)다. V03·X12 는 이 잡음 폭과 비슷하다. V02 의 2024-25 −1.73% 만 잡음보다 뚜렷하다.
- 공휴일(X17)은 나눠도 여전히 나빠서, 이 나누기가 아무 실험이나 통과시키는 착시는 아니다.
- **가장 중요한 반례는 E3 다.** 발전소별 이력으로 만든 값이라 V02 와 성격이 같고, 본 발전소만 보면 세 해 다 좋아지는데, 처음 보는 발전소가 없는 실제 평가 기간(리더보드)에서 약 300만 원 손해였다. 발전소의 과거 모습(설비 변경·장기 정지 등)이 1년 뒤에는 달라질 수 있다는 뜻으로 읽힌다.
- 이 분석은 결과를 본 뒤 만든 나누기이고, GFS 가 없는 옛 기준(E9-00, E7-00) 위의 결과다.
- 더 넓게 보면: **검증 설계가 실제 평가보다 '새 발전소 일반화'를 훨씬 더 요구한다.** 발전소 정체성을 쓰는 피처는 검증에서 불리하게, 위경도처럼 일반화되는 피처는 유리하게 평가되어 왔다. 2023-24 는 처음 보는 발전소가 99곳으로 가장 많으므로, 다른 실험에서 2023-24 만 크게 흔들린 경우에도 이 영향을 의심해 볼 수 있다(확인은 안 함).

### 6.4 같은 변수에 대한 판단이 기준 모델에 따라 뒤집혔다

| 변수 | 앞의 판단 | 뒤의 판단 |
|---|---|---|
| A·B 풍속, B 강수확률 | E4-10(E4 기준) 빼기 +0.85 / +0.16 / −0.56% → 유지 | V05(E9 기준) 빼기 통과 → 뺌 |
| 전날 요약(B 강수, A 운량·일교차) | X02b(E7 기준) 빼기 +0.63 / −1.02 / +0.36% → "셋 다 유지" | V05 에서 4개 중 3개 뺌 |

두 경우 모두 앞뒤 결과가 섞여 있다 → 이 변수들은 있어도 없어도 같다는 뜻이다. 어느 쪽으로 정했든 근거가 약하다는 점은 같다.
또 V05·V06 은 GFS 를 넣기 전(E9-00) 판단이고, GFS 모델과 설정값 탐색(T1, 열 표본 비율 0.52) 뒤에는 다시 고르지 않았다. GFS 운량이 들어오면서 지역 예보 운량 열의 몫이 바뀌었을 수 있지만 확인은 안 했다.
