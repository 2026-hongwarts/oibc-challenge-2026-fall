1. 세 해 모두 벌금이 준다.
2. **시드 잡음**: 설정은 같고 시드만 바꾼 기준 모델(N1x2, N2x2)이 +0.06 / −0.20 / +0.55%, −0.21 / −0.03 / +0.44%.

4. 같은 세 해로 여러 조합을 골랐으므로 고른 결과는 약간 낙관적이다. 최종 판정은 리더보드.
