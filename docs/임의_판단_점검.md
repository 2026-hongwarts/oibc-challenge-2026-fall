# 근거 없이(또는 약한 근거로) 정한 것 점검 (11/11 01시)

사용자 요청: "제대로 된 근거 없이 임의로 진행한 사항을 추리고, 다시 따져봐야 할 것을 점검". 사용자가 직접 정한 것(판정 규칙 유지, 3% 제출 기준, A 기압 포함, CatBoost 제외, §7 해석)은 목록에서 뺐다.

## A. 근거가 약한데 단정적으로 말한 주장 — 바로잡을 것
| # | 주장 | 실제 근거 | 바로잡기 |
|---|---|---|---|
| A1 | "내부 1% 안팎 차이는 리더보드에서 잡음(방향이 뒤집힘)" | E12-10c 한 번(내부 −0.88% → 리더보드 −53만 원) | **철회.** E12-10c 는 평가 기간 GEFS 빈 4일에 S3 가 무너지는 버그(−92 MWh, 벌금 상한 약 320만 원)가 있었다. 잡음이 아니라 버그였을 가능성이 크다 → 고친 판(E12-10cfx2_comp)을 내면 직접 확인 가능 |
| A2 | "새 정보는 리더보드로 옮겨지고 설정값·구조 개선은 절반만 옮겨진다" | 제출 두 번(E10-08: 1% ≈ 218만 원, E11-10T1: 1% ≈ 86만 원) | 표본 2개라 약함. 방향 참고만 |
| A3 | "5위는 내부 6~7%(또는 15%) 필요" | A2 의 환산을 그대로 곱한 것 | 같은 이유로 약함 |
| A4 | GFS 이전 실행 근거로 "HEFTCom 1위가 출처 추가로 +8%" | 그 +8% 는 **다른 수치예보 모델(MEPS)** 을 더한 효과. 같은 GFS 의 6시간 이른 실행과는 다름 | **과장이었음.** S4 기대치는 낮춰야 함 |
| A5 | 에어로졸 기대 "0.5~2%" → "0~1.5%" | 문헌의 방향만, 우리 문제에 맞춘 수치 없음 | 추정이라고만 했어야 함 |
| A6 | GEFS 덧붙이기 실패 이유 "희석" | 확인 실험 없음(작은 판도 실패) | 가설일 뿐 |
| A7 | GPU·CPU 차이 "시드 잡음 안" | E11-11 한 모델 2024-25 한 해(−0.18%) | 이후 세 해·두 모델에서 최대 0.9% 차이 확인 → 같은 장치끼리만 비교하는 것으로 이미 바꿈 |

## B. 근거 없이 정한 설정값·방식
| # | 무엇 | 정한 방식 | 다시 볼지 |
|---|---|---|---|
| B1 | 학습 기간 2년 | E3-05(11/8)에서 3년 +0.54%, 전체 +0.38% → 2년. **GFS·GEFS 피처를 넣기 전** 결과 | **다시 봄** — 지금은 외부 예보가 2021-06 부터 있어, 평가 기간 모델(2023-06 ~ 2025-05)에 3년(2022-06 ~)을 써도 빈칸이 없음 |
| B2 | 앙상블 같은 비중 | 모델 2~4개일 때 stack.py 시험 결과. 5~6개에서는 재시험 없음 | 낮음(비중을 맞추면 낙관치가 커짐) |
| B3 | 구성원을 더할 때 1/6 비중 | 관례 | 낮음 |
| B4 | GEFS 전용 XGBoost(S3X)를 **기본 설정값**으로 시험 | S3(LGB)는 탐색한 설정, S3X 는 안 함 → 불공정한 비교 | **다시 봄** — XGB 탐색 설정(시도 13)으로 GPU 15분 |
| B5 | MLP 레시피 | 조사 권장안에서 피처 줄이기·발전소 임베딩·조기 종료를 뺀 단순판, 에폭 20 고정 | 결과가 나쁘면 '레시피 탓'일 수 있음을 함께 적기 |
| B6 | GEFS 표준편차를 cosz 로 시각 배분 | 평균과 같은 방식으로 그냥 적용 | 점검 결과 블록마다 튐(19 ~ 21시 0.727). 고치려면 GEFS 재해석(약 2시간) + S3 재학습 — 우선순위 중간 |
| B7 | GFS 상자(북위 33 ~ 39°, 동경 124 ~ 131°)·1° 지역 | 한반도를 덮게 임의로 | 낮음(§7 고정 영역이면 충분) |
| B8 | 입력 빠짐 처리를 GFS 를 쓰는 혼합 모델(G5bT1 등)에도 적용 | 일관성 | 검증에서 2022-23 −0.2% 로 해가 없음. 유지 |
| B9 | 일출·일몰 보정 범위(고도 −4 ~ 0°, 중앙값) | 표에서 −4° 아래는 중앙값 0 | 유지(판정은 사용자) |
| B10 | 밤샘 자동 진행의 규칙(통과한 변경 모두 합치기, 안 되면 maximin, 06시 마감) | 내가 정함 | 아침에 결과와 함께 보고 |

## C. 결과를 보고 한 조치 (낙관 가능성)
| # | 무엇 | 메모 |
|---|---|---|
| C1 | E12-10c(S2T1 → S3 교체) | 미리 정한 후보가 아니었음. 시드 재현은 통과 |
| C2 | GEFS 작은 판(G7k)을 G7 실패 뒤 GPU 로 시험 | 미리 말해 둔 대비책이긴 함. 불통과 |
| C3 | 기준 앙상블 파일을 빠짐 처리판으로 **같은 이름에 덮어씀** | E12-10cx2·E11-10T1x2·E12-10cs2x2·E11-10T1s2Sx2 의 2022-23 값이 약 0.2% 바뀜. 11/10 기록의 숫자와 다를 수 있음 |
| C4 | E12-10c 를 '내부 기준'으로 삼음 | 사용자 질문 → 리더보드 최고는 E11-10T1, 3% 기준도 E11-10T1 대비로 유지 |

## D. 다시 따져서 오늘 밤 할 것
1. **B4** S3X 를 XGB 탐색 설정으로 다시(GPU 15분) — 판정: E12-10c + S3X vs E12-10c 세 해.
2. **B1** 학습 기간 3년: 자료가 2021-01 부터라 **2022-23 해는 2년판과 학습 자료가 같아 변화가 0** → '세 해 모두 개선' 규칙으로는 판정할 수 없다(일출·일몰 보정과 같은 상황). 그래서 실험은 정보용으로만(S3 3년판의 2024-25·2023-24 효과), CPU 가 빌 때 돌리고 판단은 사용자에게.
3. **A1** 은 실험이 아니라 제출로만 확인 가능 → 아침에 E12-10cfx2_comp 제출 여부를 사용자에게.
