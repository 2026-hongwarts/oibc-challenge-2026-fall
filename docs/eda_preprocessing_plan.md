# 0. 한 페이지 요약

**수익항은 상수다.** 253개소가 모두 G1 또는 G2에 들어가므로 Σ SMP·실적은 구성과 예측에 상관없이 같다. 팀 간 점수 차이는 전부 **페널티**에서 난다.

가상 평가연도(2024-06 ~ 2025-05)에서 baseline 축소판 모델로 잰 값:

| 항목 | 값 | 뜻 |
|---|---|---|
| 페널티 / 수익 | **2.98%** | 기후값 예측은 6.89%. 모델 페널티는 기후값의 43% |
| 11~15시 페널티 비중 | **82.5%** | 가격(×3)과 오차 크기가 둘 다 한낮에 몰림 |
| 참조 구성(current_group) | 하한 대비 +1.85% | 하한 = 전체를 한 포트폴리오로 봤을 때 |
| 무작위 구성 300개 | 평균 +1.60%, 최악 +3.47% | |
| **남/북 지리 분할** | **+11.96%** | 피해야 할 구성 |
| 최적화 구성 (표본 외) | +0.85% | 참조 대비 약 1%p 이득 |

**결정**

1. **시간의 대부분을 예측 정확도, 특히 11~15시에 쓴다.** 구성 최적화로 얻을 수 있는 몫은 페널티의 약 1%다.
2. 구성은 **"각 집합을 전체의 축소 복제본으로"**. 지역별로 나누지 않는다. 최종 모델의 잔차로 국소탐색해 마무리한다(수 초면 끝남).
3. 모든 실험은 **같은 검증 하네스**(가상 평가연도 + 대회 점수식)로 판정한다.
4. 제출은 **총 20회(일 3회)** 뿐이다. 하네스에서 이긴 후보만 내고, 마지막 날을 위해 여유분을 남긴다(§9).

# 1. 점수식이 말하는 것

$$S=\sum_{g}\sum_t \mathrm{SMP}_t A_{g,t} \;-\; 0.10\sum_{g}\sum_t \mathrm{SMP}_t\, k_t\,|F_{g,t}-A_{g,t}|,\qquad g\in\{G1,G2\}$$

## 1.1 제출물

- `composition.csv`: 253개소의 G1/G2 배정 **1개** (평가 기간 내내 고정). 각 집합 설비용량 ≥ 20,000 kW → 전체 42,655.4 kW 중 한쪽이 46.9% ~ 53.1%.
- `forecast.csv`: G1·G2 × 8,760시각을 **한 파일로** 제출한다. 매일 제출하는 방식이 아니다. 평가 구간에는 실적이 없으므로 최근 실적을 입력으로 쓰는 모델은 쓸 수 없다.
- 순위는 정산금 S 내림차순이고, 리더보드에 S(원)가 표시된다. 제출은 **일 3회, 대회 기간 총 20회**.

## 1.2 수익항은 상수

$A_{G1,t}+A_{G2,t}$ = 전체 실적이므로 수익항은 구성에도 예측에도 영향을 받지 않는다. 대회 목표의 "총량 고정 — 좋은 발전소만 모아 담기는 전략은 성립하지 않는다"가 이 뜻이다.

## 1.3 구성의 효과는 오차 부호에서 나온다

집합 오차 $e_g=F_g-A_g$ 에 대해

$$|e_1|+|e_2| = |e_1+e_2| + 2\min(|e_1|,|e_2|)\cdot\mathbb{1}[e_1e_2<0]$$

- 두 집합이 **같은 방향으로 틀리면** 추가 손실이 없다. 반대 방향이면 작은 쪽 오차의 2배를 더 낸다.
- 하한은 "전체를 한 포트폴리오로 예측했을 때의 페널티"다. 각 집합을 **전체의 축소 복제본**(지역·관측지점·규모가 고르게 섞인 집합)으로 만들수록 하한에 가까워진다.
- 대회 목표의 "오차 상쇄"(A는 과소, B는 과대 → 같은 집합에 묶기)와 같은 말이다. 반대 방향으로 틀리는 발전소들은 **같은 집합 안에서** 상쇄돼야 하고, 두 집합 사이에서는 상쇄가 일어나지 않는다.
- 측정 결과: 발전소 간 **예측 오차 상관**은 평균 0.35이고 거리에 따라 빠르게 줄어든다(25 km 이내 0.70 → 200 km 근처 0.19). 실적 CF 상관(평균 0.89, v1이 본 값)은 일주기 때문에 부풀려진 값이라 구성 판단에 쓰면 안 된다.

## 1.4 가중치와 최적 예측값

- 한 시각의 손실은 $w_t|F-A|$ ($w_t$ = SMP·k)이므로 $w_t>0$ 이면 최적점은 **조건부 중앙값**이고 $w_t$ 와 무관하다.
- 가중치가 작동하는 곳은 세 군데다. (a) 모델이 어느 시각에 용량을 쓸지(sample_weight), (b) 검증 지표, (c) 구성 목적함수.
- **중앙값은 집합 단위에서 맞춰야 한다.** 발전소별 중앙값의 합은 집합의 중앙값이 아니다. 그런데 실제로 재 보니 발전소 단위 L1 학습이 기준 설정에서 벌금을 1.79% 줄였다(E4-02x2, 시드 2개, 2026-10-26). 사전 실험(round 17 단독, 시드 1개)에서 본 +0.4%와 반대라서 L1을 채택하고, **집합 단위 보정**(E5-01)은 그 위에서 따로 시험한다.
- 평가 구간 SMP·k 는 `smp.csv`에 주어져 있다. SMP=0인 시각은 18개뿐이라 특별 처리할 가치가 없다.

## 1.5 페널티가 쌓이는 곳

- 시간대: 11~15시가 **82.5%**. v1의 61%는 가격만 보고 오차 크기를 빼먹은 값이었다.
- 월: 발전량 비중 대비 페널티 비중이 큰 달은 **9월(1.62배), 7월(1.49배), 10월(1.43배)**. 장마·가을 구름이 많은 달이다. 검증 점수를 월별로 쪼개 보고, 이 달들에서 개선되는지를 따로 확인한다.
- 평가 구간 SMP: 평균 108.0원, 최저 4시(89.4원), 최고 20시(120.8원). 13시에 약한 함몰(103.7원)이 있지만 k=3 덕분에 11~15시 페널티 가격은 나머지 주간의 **2.92배**다.

## 1.6 대회 규칙 — 확인된 것과 남은 것

**확인됨 (2026-10-25)**

| 규칙 | 계획에 미치는 영향 |
|---|---|
| 평가 기준은 정산금 S, 순위는 S 내림차순, 리더보드에 S(원) 표시 | 모든 팀의 수익항이 같으므로 **리더보드 S의 차이 = 페널티의 차이**. 우리 제출 두 개의 S 차이가 곧 페널티 차이(원)다 |
| 일 3회, 총 20회 제출 | 리더보드로 실험하면 안 된다. 하네스가 1차 판정, 리더보드는 확인용 (§9) |
| 외부 라이브러리 사용 가능 | `pvlib`로 청천 일사(Ineichen)와 정밀 태양 위치 계산(§5). CatBoost·XGBoost도 사용 가능 |

**아직 모름 — 확인 필요**

| 항목 | 왜 중요한가 |
|---|---|
| 리더보드가 평가 구간 **전체**로 계산되나, public/private으로 나뉘나 | 전체라면 리더보드 S가 최종 점수와 같아서 리더보드 비교를 그대로 믿어도 된다. 나뉜다면 public에 맞추는 과적합을 경계해야 한다 |
| 최종 순위에 쓰는 제출: 최고 점수 / 마지막 / 직접 선택 | 마지막 날 제출 방식이 달라진다(§9) |
| 평가 구간 실적에 빈 시각·정지가 있을 때 집합 실적을 어떻게 계산하나 | 정지 발전소가 0으로 합산되면 과대예측 위험이 커진다 |
| 외부 **데이터**(라이브러리 말고) 허용 여부 | 기본값은 사용 안 함 |
| 동점 처리, 제출 기간 시작일 | v1에 적힌 대회 기간 11/02 ~ 11/13을 가정하고 §9를 짰다 |

# 2. 데이터 사실

## 2.1 발전소와 편입 시점

- 253개소, 42,655.4 kW. **203개소가 100 kW 이하**이고 용량 상위 10개가 총용량의 24.7%다.
- 편입 연도: 2021년 31 · 2022년 49 · 2023년 68 · **2024년 105**개소 (2024년 2분기에만 50개).
- 가상 평가연도 시작(2024-06-01) 이후 편입 48개소. 실제 평가 시작 시점에 이력 1년 미만도 48개소이고, 가장 짧은 곳은 158일이다.
- → 발전소별 개별 모델은 불가. **발전소를 섞어 학습하는 pooled 모델**이 기본이다.
- 관측지점: WA 61개, WB 73개. 지점당 발전소 중앙값 2개, 최대 20개(WA) · 18개(WB).

# 3. v1 대비 바뀐 판단

v1 계획서·노트북을 검토한 결과다. 틀린 것은 고쳤고, 근거가 약한 것은 뺐다.

| v1 내용 | 문제 | v2 |
|---|---|---|
| "수익항은 구성으로 결정 — 좋은 발전소를 많이 넣을수록 수익↑" | 수익항은 상수 | 페널티만 최소화 (§1.2) |
| "예측: 매일 제출" | 1년치 파일 1회 제출 | §1.1 |
| 구성: "음의 상관 발전소를 같은 그룹에", 근거로 실적 CF 상관 | 목적함수가 틀린 대리지표. 실적 상관 0.89는 일주기 효과 | 오차 잔차로 직접 최적화, 복제본 원칙 (§7) |
| 11~15시 페널티 비중 61% | 가격만 반영 | 실제 오차 반영 82.5% |
| 상관 분석: 고정 6~18시, 원 CF | 일주기 교란 | 태양고도 기준 + CSI |
| 커버리지 지표 "0/253" | 편입 전 기간 포함 | 편입 후 99.98% |
| 평가 WA 결측 `isnull()` → "결측 없음" | 결측은 행 단위 | 격자 재색인, 라운드 대체 |
| 실측 기상 오차를 9999 포함해 계산 | 풍속 RMSE 22.4 왜곡 | 이상값 NaN 후 계산 |
| 산점도 `wb_humidity` | 없는 열 → 그래프 누락 | `wb_rel_hum` |

| DTW 클러스터링 | 시각이 정렬된 점수식과 맞지 않음 | 제외 |

# 4. 전처리 (확정)

## 4.1 발전량 (타깃)

1. `energy < 0` → 0.
2. **정지·고장일 제외(학습에서만)**: 태양고도 > 5°인 시간의 일 발전량 ≤ 설비용량 × 1%인 (발전소, 날짜). `dead_days()`로 계산해 `outputs/eda/dead_days.parquet`에 저장했다.
   - **검증 실적에서는 빼지 않는다.** 평가 구간에서도 정지는 일어나고, 그 오차도 점수에 들어간다.
3. 부분 정지(동시각 다른 발전소 중앙 CF ≥ 0.3인데 혼자 CF ≤ 0.02)는 시각 단위 제외 **후보**다. 효과를 실험으로 확인한 뒤 결정한다.
4. 결측 보간은 하지 않는다. 편입 이전 기간은 행이 없으므로 자연히 빠진다.
5. 타깃은 CF(= energy / capacity_kw). 맑은날 기준 곡선으로 나눈 CSI 타깃은 실험 후보.

## 4.2 예보

1. 평가 WA 빠진 264행: 같은 지점·시각의 다른 라운드로 채운다(`fill_round_gaps`). 남는 결측 0.
2. 학습 구간 빠진 행·NaN: 그대로 둔다(LightGBM이 처리).
3. 라운드: (지점, 시각)당 한 행으로 펼친다 → `r17` 값, `r10` 값, `r17 − r10`.
4. 단위 통일(WB 풍속 km/h → m/s)은 두 제공사 값을 섞은 합성 피처를 만들 때만 한다. 트리 모델 입력에는 필요 없다.

## 4.3 실측 기상

모델 입력으로 쓰지 않는다(평가 구간에 없음). 예보 품질 진단과 정지일 판별 보조에만 쓴다. README의 이상값 6종은 NaN으로 바꾼 뒤 사용한다.

## 4.4 시간축

모든 `ts`는 KST tz-aware, 우측닫힘. 태양 기하는 구간 중앙(−30분)으로 계산한다(baseline과 같음). 날짜 키는 `ts − 1h`의 날짜(`day_of`). 예보와 발전량은 `ts` 그대로 병합한다(§2.3 정렬 검증).

# 6. 검증 설계

**주 검증: 가상 평가연도 1개**

- 학습 ≤ 2024-05-31, 검증 **2024-06-01 01:00 ~ 2025-06-01 00:00**. 실제 평가(마지막 데이터 이후 한 해를 한 번에 예측)와 구조·계절이 같다.
- 지표: 대회 점수식의 페널티(G1+G2), 가중치 = 학습 구간 SMP × k (`oibc_common.score`). 월별·시간대별로도 쪼개 본다.
- 보고: (a) 전체 발전소 · 참조 구성 점수, (b) 검증연도 전체 이력이 있는 205개소 기준 구성 분석.

**한계와 보조 검증**

- 2024-06 이후 편입한 48개소는 이 검증에서 학습 이력이 0이다. 실제 평가에서는 모든 발전소가 158일 이상 이력이 있다. 그래서 이 검증은 신규 발전소에 대해 실제보다 가혹하다.
- 최종 후보 2~3개만 보조 2-fold로 재확인한다: (≤ 2024-11 → 2024-12 ~ 2025-05), (≤ 2024-05 → 2024-06 ~ 2024-11).

**규칙**

- 공통 도구(2026-10-26): `src_tools/build_base.py`(공통 테이블), `src_tools/evaluate.py`(채점기), `src_tools/train_site_model.py`(기본값 = baseline 재현 E4-00). 기준 모델은 `outputs/preds/champion.txt`.
- **시드 잡음**: 같은 설정에서 시드만 바꿔도 가상 평가연도 벌금이 0.51% 움직였다(E4-00 seed 0: 223,063,809원 / seed 1: 224,191,598원). 그래서 채택 판단은 `--seeds 2`(시드 2개 예측 평균)끼리 비교한다. baseline 재현 E4-00x2 = 223,140,191원, 2026-10-26 병합 후 기준 모델 E1-01x2 = 214,063,738원(아래 §8 결과표). 실험은 `--base champion` 위에 변경 하나를 얹어 돌린다.

- 맑은날 기준 곡선처럼 타깃에서 만드는 피처는 각 fold의 학습 구간에서만 계산한다.
- 최종 제출 모델은 전체 기간(또는 실험으로 정한 기간)으로 재학습한다.

# 7. 구성 전략

1. **원칙**: 두 집합이 같은 방향으로 틀리게 → 지역·관측지점·규모를 고르게 섞는다. 지역 분할 금지(+12%).
2. **알고리즘**: 잔차 행렬 $R$(시각 × 발전소, 예측 − 실적, kWh)에서 발전소 1개를 반대 집합으로 옮기는 이동 중 최선을 반복한다(`local_search`). 모든 후보의 개선량을 한 번에 벡터로 계산하므로 수 초면 끝난다. GA·SA는 필요 없다.
3. **제약**: 각 집합 ≥ 20,000 kW. 205개소 시뮬레이션에서는 비율(46.9%)로 적용한다. 최종은 253개소 절대값으로 적용한다.
4. **입력**: 최종 모델의 검증연도 잔차. 모델이 바뀌면 최적 구성도 바뀌므로 마지막에 한다.
5. **안정성**: 시작점 여러 개 + 월 단위 부트스트랩에서 대부분 같은 집합에 배정되는 발전소는 확정하고, 흔들리는 발전소는 용량 균형과 지점 분산으로 정한다.
6. **신규 48개소**: 검증연도 잔차가 일부만 있다. 같은 관측지점을 쓰는 기존 발전소와 나눠 배치해 각 집합에 고르게 섞는다.
7. **기대 이득**: 참조 구성 대비 페널티 약 1% 감소. 작지만 거의 공짜다.

# 8. 모델링 방향과 실험 순서

과제의 본질은 **기상예보 후처리 회귀**(예보 → 발전량)다. 평가 구간에 최근 실적이 없으므로 시계열 자기회귀 계열 모델은 이점이 없다. 주력은 LightGBM pooled 모델이다.

**파이프라인**: 발전소 단위 CF 모델(L1, 2026-10-26 채택) → 집합 합산 → 집합 단위 보정 → 제출

**실험 순서** (각 실험은 하네스 점수로 판정, 개선분만 누적):

| # | 실험 | 기대 |
|:-:|---|---|
| 0 | baseline.py 그대로(라운드 10·17 예측 평균) 하네스 점수 재현 | 출발점 |
