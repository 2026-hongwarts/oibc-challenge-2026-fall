# 제출 기록

제출은 하루 3회(다음 날로 이월 안 됨), 대회 기간 총 20회. 리더보드 값은 정산금 S(원)이고, 수익항은 모든 제출이 같으므로 **두 제출의 S 차이 = 벌금 차이**다.

**최종 순위 = 제출 중 최고 점수** (사용자 확인, 11/8). 나쁜 제출은 손해가 없고, 하루 3회는 이월되지 않는다. **형식 오류로 무효가 된 제출도 횟수에 포함**된다(규정 §2).

원칙: 세 해 검증(2024-25, 2023-24, 2022-23)으로 후보를 거르고, 남은 후보 중 기대 효과가 큰 것부터 제출한다.
**제출 기준(11/10 사용자 결정, 11/9 의 '내부 4~8%' 를 대체)**: 현재 리더보드 최고 제출(11/12 부터 E13-13ftx2_comp)보다 내부 검증 세 해 합 벌금이 **3% 이상** 낮은 후보(각자 구성 기준, `compare_own_comp.py`)가 나오면 제출한다. 하루 3회·이월 없음.
**규정 §2: 리더보드 점수를 보면서 배율, 혼합 가중치, 그룹을 반복해 고치는 제출은 허용되지 않는다.** 그래서 묶음 배율 α, 앙상블 비중, 구성은 내부 검증으로만 정하고 리더보드로 맞추지 않는다. 각 후보는 제출 전에 내부 검증만으로 완성해 둔다. 전체 규정과 점검은 [대회_규정.md](대회_규정.md).
