# 제출 기록

제출은 하루 3회, 대회 기간 총 20회. 리더보드 값은 정산금 S(원)이고, 수익항은 모든 제출이 같으므로 **두 제출의 S 차이 = 벌금 차이**다.

| 날짜 | 제출 파일 (`outputs/submissions/`) | 모델 | 리더보드 S (원) | 메모 |
|---|---|---|---|---|
| (11/7 이전 제출이 있으면 여기에) | | | | |
| 11/7 | `E2-finalx2/` | E2-final (기준 모델) | 6,444,992,*** | |
| 11/7 | `E3-finalx2/` | E2-final + 맑은날 기준값(E3-02b) | 6,444,989,*** | E2-final 보다 약 300만 원 낮음 → E3 기각. 다른 해 검증(+0.3~0.4%)과 같은 방향 |
